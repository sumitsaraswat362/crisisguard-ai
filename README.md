## 🚀 Overview

**CrisisGuard AI** is a real-time, privacy-first NLP platform designed to detect mental health crisis signals in digital text (messages, posts, chat logs) and provide clinical-grade severity scoring and contextual AI advice. 

Unlike generic chatbots, CrisisGuard is a **systemic triage tool** built for institutional responders, community managers, and clinical intake teams.

## 💡 The Problem
Millions of crisis signals go undetected in digital communications. Organizations lack the tools to proactively identify at-risk individuals before it's too late. When they do use tools, they often compromise user privacy by sending sensitive data to third-party APIs.

## 🛡️ The Solution
CrisisGuard AI uses a multi-layer NLP pipeline running **100% locally in the browser**. No data ever leaves the user's device, ensuring complete privacy by design.

### Key Features:
- 🧠 **Multi-Layer NLP Engine**: Detects 9 categories of crisis indicators including Suicidal Ideation, Violence, Severe Distress, Self-Harm, and Hopelessness.
- ⚡ **Real-Time Analysis**: Millisecond response times for continuous monitoring.
- 🔒 **Zero-Data Retention**: Client-side inference means absolute privacy.
- 📊 **Clinical-Grade Triage**: Calculates a 0-100 severity score based on sentiment modifiers, temporal urgency, and protective factors.
- 🤖 **Contextual AI Advice**: Generates situational response protocols based on the specific text analyzed.
- 🎨 **Premium UI/UX**: Interactive neural network background, glassmorphism cards, and live monitoring dashboards.

## 🛠️ Tech Stack
- **Frontend Core**: HTML5, CSS3, Vanilla JavaScript
- **Data Visualization**: Chart.js
- **Machine Learning**: Custom Client-Side Lexical & Semantic NLP Engine
- **Visuals**: HTML5 Canvas (Neural Network Particle Mesh)

## 🖥️ Try it Locally

Since CrisisGuard AI has no backend dependencies, running it is incredibly simple:

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/crisisguard-ai.git
   ```
2. Navigate to the directory:
   ```bash
   cd crisisguard-ai
   ```
3. Open `index.html` in any modern web browser, or serve it locally:
   ```bash
   python3 -m http.server 8080
   ```
4. Navigate to `http://localhost:8080`
