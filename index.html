About CrisisGuard AI

Built for UOE Summer of Code 2026

🎯 The Problem

Millions of crisis signals go undetected in digital communications. Organizations lack tools to proactively identify at-risk individuals.

💡 Our Solution

Multi-layer NLP pipeline analyzing text for crisis indicators using sentiment analysis, contextual patterns, and severity scoring.

🏗️ Architecture

Client-side inference, multi-stage pipeline, real-time analytics, PWA architecture. Zero external dependencies for core analysis.

🔒 Privacy First

All analysis in-browser. No data sent externally. No storage. People in crisis deserve protection, not surveillance.
